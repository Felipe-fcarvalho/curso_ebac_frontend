# A entrega desse exercício consistia em:

- Criar um arquivo HTML que continha um formulário de cadastro, com os campos nome, e-mail e senha e a existência de um botão para realizar o cadastro;
- Adicionar também uma label para cada campo e referenciar essa label ao ID atribuída ao campo;
- Enviar o arquivo para o Github em uma branch chamada exercício_html;
