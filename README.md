# JavaScript 

## O exercício deste módulo consistia em:

1) Criar um formulário HTML que tivesse dois campos numéricos:
- campo A
- campo B

2) Inserir um botão para submeter o formulário.

3) Criar uma validação no JavaScript, na qual o formulário apenas seria válido caso o número B fosse maior que o número A.

4) Exibir uma mensagem positiva para o usuário quando o formulário fosse válido e uma mensagem negativa quando fosse inválido.

5) Subir no Github no repositório do curso em uma branch chamada exercicio_html_js.
