# JavaScript 

## O exercício deste módulo consistia em:

1) Criar um formulário HTML que tivesse dois campos numéricos:
campo A
campo B

2) Inserir um botão para submeter o formulário.

3) Criear uma validação no JavaScript, na qual o formulário seria válido caso o número B seja maior que o número A.

4) Exibir uma mensagem positiva para o usuário quando o formulário for válido e uma mensagem negativa quando for inválido.

5) Subir no Github no repositório do curso em uma branch chamada exercicio_html_js.
